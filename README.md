# GTA 5 Style Food Items Collection

A collection of stylized food item illustrations featuring fake GTA 5 parody brands, created for the community.

## About

This repository contains a curated collection of food item illustrations designed in a consistent, bold graphic style reminiscent of Grand Theft Auto V's in-game branding. Each item features fictional parody brands using locations from the GTA universe (Vinewood, Los Santos, San Andreas) with no real brand names or logos.

All items are designed with:
- Bold black outlines
- Vibrant, saturated colors
- Smooth gradients and 3D shading
- Glossy highlights
- Transparent backgrounds for easy integration
- Premium, ornate label designs
